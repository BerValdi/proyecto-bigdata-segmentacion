# Proyecto Big Data - Segmentación de Usuarios

Curso: INF3862 - Plataformas Big Data para Data Science

## Objetivo
Diseñar una plataforma de datos que integre información de actividad física de dispositivos wearables con registros de recetas preparadas de Food.com, para analizar y segmentar usuarios según sus patrones de comportamiento.
